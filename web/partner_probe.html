相手モードの確認: VB-CABLE に声を流す

http://127.0.0.1:8000/partner_probe.html で開く。AivisSpeech が動いている必要がある。

  1. 「機器を探す」で CABLE Input と CABLE Output を探す (マイクの許可を求められたら許可する)。
  2. 「CABLE に流す」で文章を合成して CABLE Input に流す。下のメーターで、CABLE Output に届いた音の大きさを見る。
    • 素: エコー除去なしで CABLE Output を録った大きさ。
    • AEC: エコー除去ありで録った大きさ (ChatGPT のタブのマイクに近い)。素より大きく下がれば、Chrome のエコー除去が idle-talk の声を消している。
  3. ChatGPT の音声会話のマイクを CABLE Output にして同じ操作をし、ChatGPT が答えるかを見る。
